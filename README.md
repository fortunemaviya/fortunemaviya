#### 🔭 Featured project

**[USD/JPY deep learning: what is actually predictable?](https://github.com/fortunemaviya/usdjpy-deep-learning)**
An end-to-end study on 27 years of Federal Reserve data: an LSTM ensemble re-trained every year, benchmarked against the models practitioners use (HAR, GARCH, gradient boosting), with leakage tests, a pre-registered hypothesis and significance tests.

- **Daily direction:** no model beat a coin flip over 2,942 out-of-sample days. Built properly, the "AI predicts forex" edge disappears.
- **Next-week volatility:** the LSTM explained 28% out of sample and beat the standard HAR model (p = 0.017), level with GARCH.

`PyTorch` · `scikit-learn` · `arch` · `pandas` · `walk-forward validation` · `Diebold-Mariano tests` · `GitHub Actions`
